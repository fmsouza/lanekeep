# Gemini instructions

The working guide for this repository is [`AGENTS.md`](AGENTS.md). Read it first — it
covers the commands, the repository map, the invariants that must not be broken, and the
traps already discovered here.

The design authority is [`docs/architecture.md`](docs/architecture.md).

This file is deliberately a pointer. Duplicating guidance per tool produces copies that
drift, and a drifted copy is worse than no copy because it is trusted.
